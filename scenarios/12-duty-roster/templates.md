# 模板｜值日/轮值安排

## 模板 1｜按周轮值
**用：** 周值日、岗位轮值

```text
岗位：[岗位]
周期：[周期]

| 周次 | 人员 |
|------|------|
| 第1周 | [学生1]、[学生2] |
| 第2周 | [学生3]、[学生4] |
| 第3周 | [学生5]、[学生6] |
| 第4周 | [学生7]、[学生8] |

值日要求：
- [要求1]
- [要求2]

请假提前说，当天找人替。
```

## 模板 2｜按日值日
**用：** 每日值日、短周期轮换

```text
| 日期 | 岗位 | 人员 |
|------|------|------|
| 周一 | [岗位] | [人员] |
| 周二 | [岗位] | [人员] |
| 周三 | [岗位] | [人员] |
| 周四 | [岗位] | [人员] |
| 周五 | [岗位] | [人员] |
```

## 模板 3｜班级群公告版
**用：** 发班级群或公告

```text
同学们，本阶段值日安排如下，按要求完成。
有特殊情况提前说，不要临时缺岗。

安排周期：[安排周期]
执行要求：[执行要求]
```
