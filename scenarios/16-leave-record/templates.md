# 模板｜请假登记

## 模板 1｜班主任留档
**用：** 内部登记、后续跟进

```text
【请假登记】
学生：[学生姓名]
请假日期：[请假日期]
时长：[请假时长]
原因：[请假原因]
预计返校：[返校时间]
备注：[备注]
```

## 模板 2｜科任老师同步
**用：** 向科任老师同步缺课

```text
[学生姓名]因[原因]于[请假时间]请假，预计[返校安排]返校。
当日作业需要补的，我这边统一跟进。
```

## 模板 3｜家长确认
**用：** 与家长确认请假信息

```text
已收到[学生姓名]的请假说明，请假时间[请假时间]。
返校时间如有变化请及时告知。请留意[提醒事项]。
```
