# 模板｜家长群日常通知

## 模板 1｜标准通知
**用：** 常规家长群通知
**风格：** 正式、简洁

```
各位家长好：

明天[事项]，请孩子于[时间]前到达[地点]，并提前准备好[要求]。
[补充说明]

感谢配合！
[班主任姓名]
[日期]
```

## 模板 2｜快速提醒
**用：** 群内短提醒
**风格：** 简短

```
家长好，提醒一下：明天[事项]，请孩子于[时间]前到达[地点]，准备好[要求]。感谢配合。
```

## 模板 3｜需回执确认
**用：** 需要家长回复"收到"的通知
**风格：** 明确

```
各位家长好：

关于[事项]，请于[截止时间]前回复"收到"，并协助孩子准备好[要求]。
时间：[时间]
地点：[地点]

感谢配合！
[班主任姓名]
```

## 提醒
- 群通知优先短句，涉及时间/地点/材料分行写
- 一条通知只说一件事
- 有截止时间的往前放
