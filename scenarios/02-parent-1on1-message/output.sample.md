# 输出示例｜一对一家长沟通

## 示例 1｜问题反馈

```text
陈浩妈妈好，和您沟通一下孩子近况。

最近一周课堂作业有三次未按时交，数学和英语各一次未订正。已经找孩子谈过，他也意识到问题。

麻烦您在家检查一下作业完成情况，尤其是订正部分。有情况随时联系我。
```

## 示例 2｜进步反馈

```text
王悦爸爸好，分享一个好消息。

孩子这周课堂发言明显多了，数学课主动回答两次，语文朗读也比上学期流畅。

在家也多鼓励，保持住这个势头。感谢配合！
```

## 示例 3｜电话提纲

```markdown
### 电话沟通提纲
1. 来意：张伟近期课堂纪律
2. 事实：本周三次自习课大声说话，影响周围同学
3. 已做：课后谈话一次，调换座位
4. 配合：家长了解原因，提醒课堂纪律
5. 收尾：感谢，后续保持联系
```
