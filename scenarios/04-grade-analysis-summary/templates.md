# 模板｜成绩分析结论

## 模板 1｜班级整体分析
**用：** 班级考试复盘

```markdown
## 班级成绩分析

### 结论
[一句话结论，先说结果]

### 数据
| 指标 | 数值 |
|------|------|
| 平均分 | [平均分] |
| 及格率 | [及格率] |
| 优秀率 | [优秀率] |

### 分科表现
1. [科目A]：[结论+数据]
2. [科目B]：[结论+数据]
3. [科目C]：[结论+数据]

### 问题与建议
- [问题1] → [建议1]
- [问题2] → [建议2]
- [问题3] → [建议3]
```

## 模板 2｜重点学生跟进
**用：** 识别需跟进学生，内部工作稿

```markdown
## 重点关注学生

| 学生 | 问题 | 变化 | 跟进动作 |
|------|------|------|----------|
| [学生A] | [问题表现] | [变化] | [建议动作] |
| [学生B] | [问题表现] | [变化] | [建议动作] |
| [学生C] | [问题表现] | [变化] | [建议动作] |
```

## 使用提示
- 先结论，再数据，再建议
- 建议对应前面的问题
- 没有数据不编造数字
