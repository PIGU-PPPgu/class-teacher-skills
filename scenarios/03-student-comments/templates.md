# 模板｜学生评语

## 模板 1｜标准评语
**用：** 期末评语、阶段总结
**风格：** 具体、有引用、短结尾

结构：[具体优点] → ['引用句'] → [转折+改进] → [短结尾]

```
你[具体优点，用逗号分隔]。'[古文/成语/格言]'，[改进建议]，[短结尾]。
```

范例：
```
你工作认真，作业优秀，晨读积极，艺术和实践获奖，全面发展。'克己复礼为仁'，若能减少课堂扰乱、提高专注力，会更好，祝贺你！
```

```
你作为课代表加分，单科班级第一，作业优秀，艺术和实践表现卓越。'百尺竿头更进一步'，望你按时完成作业、整理内务和桌椅，期待突破！
```

```
你成绩卓越，获全年级单科状元，自主学习强，作业优秀，完成社会实践，晨读佳，艺术赛事一等奖，'会当凌绝顶，一览众山小'。仅作业未完成需注意。期待你下学期更完美，祝贺你的辉煌成就！
```

## 模板 2｜偏鼓励
**用：** 需要多一些正向反馈的学生

```
你[具体优点]。'[引用]'，若能[改进]，你会更[正面预期]，[短结尾]。
```

范例：
```
你这学期表现出色，自主学习能力强，课堂上积极举手答问，行为上认真负责，主动帮忙同学，还获得校级艺术赛事一等奖，真可谓'宝剑锋从磨砺出'！但偶尔作业未完成或注意力不集中，期待你下学期更专注，祝你继续进步！
```

## 模板 3｜批量快速版
**用：** 全班50人批量生成
**风格：** 简洁、但每条不能一样

```
你[2-3个具体优点]。'[引用]'，[一个具体改进点]，[短结尾]。
```

注意：
- 每条评语的引用句必须不同
- 优点写具体事，不堆形容词
- 改进点因人而异，不能每条都写"提高专注力"
- 有进步就写进步，没有不编

## 可用引用句库

| 格言 | 适用 |
|------|------|
| 克己复礼为仁 | 自律不够的学生 |
| 温故而知新 | 学习方法需改进 |
| 细节决定成败 | 粗心、不细致 |
| 业精于勤荒于嬉 | 贪玩、不够投入 |
| 志不强者智不达 | 有潜力但不够努力 |
| 书山有路勤为径 | 需要更多勤奋 |
| 宝剑锋从磨砺出 | 有突出表现 |
| 百尺竿头更进一步 | 成绩好的学生 |
| 会当凌绝顶，一览众山小 | 年级前几名 |
| 静以修身 | 午休吵闹 |
| 学如逆水行舟 | 需要持续努力 |
| 行成于思毁于随 | 有抄作业行为 |
| 不积跬步无以至千里 | 需要积累 |
| 锲而不舍金石可镂 | 坚持就有成效 |
| 少年辛苦终身事 | 成长提醒 |
| 一勤天下无难事 | 勤奋型 |
| 玉不琢不成器 | 有潜质但需磨砺 |

## 禁止写法

❌ "你在本阶段的学习和班级生活中表现出积极、热心的一面"
❌ "相信只要你继续保持...今后一定会有更好的表现"
❌ "这一点值得肯定"
❌ "同时，也希望你在今后的学习中进一步注意..."
❌ 只堆"活泼开朗、乐于助人"等空泛形容词
