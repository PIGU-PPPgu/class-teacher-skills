# 模板｜班级周计划

## 模板 1｜周计划
**用：** 老师自用、内部协作

```markdown
# 第[X]周班级工作计划
时间：[日期] - [日期]

## 本周重点
1. [重点事项1]
2. [重点事项2]
3. [重点事项3]

## 每日安排
| 日期 | 事项 |
|------|------|
| 周一 | [事项] |
| 周二 | [事项] |
| 周三 | [事项] |
| 周四 | [事项] |
| 周五 | [事项] |

## 截止事项
- [截止日期]：[事项]

## 备注
- [补充说明]
```

## 模板 2｜简版班务提醒
**用：** 快速汇总本周工作

```text
本周重点：
1. [事项1]
2. [事项2]
3. [事项3]

截止提醒：
- [截止时间]前完成[事项]
```

## 使用提示
- 先抓重点，再拆每日
- 每天事项不超过3条
- 截止类任务单独列出
