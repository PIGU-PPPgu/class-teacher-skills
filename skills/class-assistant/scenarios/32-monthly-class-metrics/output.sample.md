## 示例 2｜月度结论摘要

- 出勤：97.8%，张明请假3天需关注
- 作业：92.5%，英语作业提交率连续2月偏低
- 纪律：14分，比上月减少6分，午休改善是主因
- 表扬：45人次，课堂发言和作业质量双提升
- 主要趋势：纪律持续改善，英语作业是短板
- 需持续关注：张明出勤、英语缺交群体
- 下月重点：联合英语老师制定缺交学生追踪方案
