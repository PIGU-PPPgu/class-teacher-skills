# 模板｜家长会发言提纲

## 模板 1｜标准提纲
**用：** 5分钟发言

```markdown
## 家长会发言提纲

### 开场（30秒）
- 主题：[本次主题]

### 班级情况（1分钟）
- 学习：[结论]
- 纪律：[结论]
- 整体：[一句判断]

### 当前问题（1.5分钟）
1. [问题+数据]
2. [问题+数据]
3. [问题+数据]

### 家长配合（1.5分钟）
- [具体动作1]
- [具体动作2]
- [具体动作3]

### 后续计划（30秒）
- [计划1]
- [计划2]
```

## 注意
- 每个问题配一个数据或事实
- 建议落到家庭作息、作业、手机管理等可执行事项
- 不超过5分钟，说重点
