     1|# 场景 06｜班级周计划 / 班务提醒
     2|
     3|## 场景目标
     4|帮助老师把一周内的重点工作、每日安排和待办事项整理成清晰的班级周计划或班务提醒，便于执行和追踪。
     5|
     6|## 适用时机
     7|- 每周前统一梳理班务工作时
     8|- 需要给自己或搭班老师整理本周重点时
     9|- 需要把班会、值日、收缴、活动等事项排进周计划时
    10|
    11|不适合：
    12|- 需要精确到分钟级的复杂排班
    13|- 替代正式校务日历系统
    14|
    15|## 输入
    16|### 必填
    17|- 时间范围
    18|- 本周重点事项
    19|
    20|### 可选
    21|- 每日安排
    22|- 截止事项
    23|- 班级活动
    24|- 需要提醒的对象
    25|- 输出风格（清单式 / 日历式 / 简版）
    26|
    27|### 缺失时默认处理
    28|- 未给每日安排：按重点事项生成周清单
    29|- 未给风格：默认清单式
    30|- 未给对象：默认老师自用班务提醒口径
    31|
    32|## 输出
    33|默认输出：
    34|- 1 份班级周计划 / 班务提醒清单
    35|
    36|可选输出：
    37|- 按天拆分版
    38|- 家长群可发送版
    39|- 教师内部协作版
    40|
    41|## 推荐语气
    42|- 清楚
    43|- 执行导向
    44|- 简洁
    45|
    46|## 文件说明
    47|- `templates.md`：周计划模板
    48|- `examples/`：脱敏输入输出样例
    49|
    50|## 直接给 AI 的说法
    51|- 帮我整理下周班级周计划
    52|- 按周一到周五帮我拆开
    53|- 帮我做成可发给搭班老师的版本
    54|
    55|## 注意事项
    56|- 重点事项不超过 3-5 个
    57|- 截止时间尽量写明确
    58|- 可执行优先于好看
    59|

## 风格要求
输出风格严格遵循 `skills/VOICE_ANCHOR.md`。禁止使用套话式鼓励、万能结尾、空泛形容词。
