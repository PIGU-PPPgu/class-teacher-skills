# 模板｜一对一家长沟通

## 模板 1｜问题反馈
**用：** 作业、课堂状态、行为习惯等日常沟通

```text
[家长称呼]好，和您沟通一下孩子近况。

最近观察到[具体事实]，比如[场景/事例]。学校这边已[已做措施]。

麻烦您在家也留意[配合动作]，有情况随时联系。
```

## 模板 2｜进步反馈
**用：** 向家长反馈积极变化

```text
[家长称呼]好，分享一个好消息。

孩子在[方面]进步明显，比如[具体事实]。

建议在家也多鼓励，保持住。感谢配合！
```

## 模板 3｜电话沟通提纲
**用：** 先整理口头沟通逻辑

```markdown
### 电话沟通提纲
1. 来意：[主题]
2. 事实：[具体表现]
3. 已做：[措施]
4. 配合：[家长需要做的]
5. 收尾：感谢，后续保持联系
```

## 注意
- 先写事实，不下判断
- 建议具体到可执行动作
- 不用"值得肯定""让我们一起"等套话
