## 示例 1｜标准周报

```text
【班级周报】第12周 七（3）班

一、本周总体情况
班级整体稳定，纪律有改善，作业完成率提升至 95%。个别学生上课注意力仍需关注。

二、学习
数学单元测平均分 82，比上周升 3 分。英语听写优秀率 78%。语文阅读理解失分集中在第 3 题（概括段意），已安排专项练习。

三、纪律与常规
迟到 2 人次（张xx、赵xx），已谈话。午休纪律明显好转，无扣分。

四、活动与亮点
周五班会课"诚信"主题辩论，陈xx表现突出。班级黑板报获年级二等奖。

五、家校沟通
本周沟通 6 人次，重点：刘xx情绪问题跟进中，已与心理老师对接；孙xx家长反映作业量大，已协调各科调整。

六、下周重点
- 期中考试前复习安排
- 刘xx心理辅导第二次
- 语文阅读专项训练启动
```
