     1|# 场景 14｜班级周报
     2|
     3|## 场景目标
     4|把一周内班级的学习、纪律、活动与家校沟通情况浓缩成一份可读、可复盘、可继续跟进的周报。
     5|
     6|## 适用时机
     7|- 每周结束后做班级整体复盘
     8|- 需要向自己、搭班老师或年级组汇总本周情况
     9|- 需要把日报零散信息整合成周维度结论
    10|- 需要沉淀下周重点工作
    11|- 不适合替代正式总结材料或对外宣传稿
    12|
    13|## 输入
    14|- 必填信息：周次、班级、本周重点情况
    15|- 可选信息：出勤趋势、学习表现、纪律问题、活动亮点、家校沟通、下周计划
    16|- 缺失时默认：按“本周概况—亮点—问题—下周跟进”输出
    17|
    18|## 输出
    19|- 默认输出：一版内部周报
    20|- 可选输出：简版汇报、家校沟通素材版、月报素材版
    21|- 输出对象：班主任、内部协作老师
    22|
    23|## 推荐语气
    24|- 客观
    25|- 概括清楚
    26|- 不堆流水账
    27|- 有结论感
    28|- 便于后续行动
    29|
    30|## 文件说明
    31|- `templates.md`：周报结构模板
    32|- `examples/`：脱敏输入输出样例
    33|- `scripts/`：如后续需要可接入日报汇总脚本
    34|
    35|## 直接给 AI 的说法
    36|- 请把这周班级情况整理成一版内部周报。
    37|- 请根据这几天日报，提炼成本周亮点、问题和下周重点。
    38|- 请给我一版适合老师自己复盘的班级周报，不要写太空。
    39|
    40|## 注意事项
    41|- 周报重点是归纳，不是重复每天流水账
    42|- 默认用于内部，不直接公开学生个体细节
    43|- 涉及敏感情况时，保留必要结论即可
    44|

## 风格要求
输出风格严格遵循 `skills/VOICE_ANCHOR.md`。禁止使用套话式鼓励、万能结尾、空泛形容词。
