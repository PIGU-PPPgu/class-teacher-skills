# 输出示例｜谈话记录

### 谈话记录

| 项目 | 内容 |
|------|------|
| 时间 | 3月12日 午休 |
| 地点 | 办公室 |
| 对象 | 李明（初二3班） |
| 参与人 | 班主任 |

**背景**
李明近两周作业三次未交，数学课两次趴桌睡觉。

**内容**
1. 问原因：说晚上玩手机到12点，早上起不来
2. 让他把手机交给家长保管，他同意
3. 约定每天晚10点前睡觉

**学生状态**
- 情绪：平静，不抵触
- 配合度：愿意试
- 认知：承认问题在自己

**约定**
- 手机交家长，周末可用1小时
- 每天作业由同桌提醒检查

**跟进**
- 周五联系李明妈妈确认手机管理落实情况
- 下周一查作业完成记录
