# 输出示例｜重点学生阶段观察卡

## 示例 1｜标准观察卡

```text
学生：刘xx
观察周期：2024-11-11 ~ 11-22（第11-12周）
当前关注点：情绪低落、课间独处、作业质量下降
学习状态：作业按时交但字迹潦草、错误率升高；课堂回答减少，不主动举手
纪律表现：无违纪，但上课走神频率增加（本周观察到4次）
情绪状态：低落。课间多独坐，不参与同学聊天。无哭泣或过激行为。
同伴互动：减少。原与陈xx、赵xx常在一起，近两周主动回避
家长反馈：父亲反映在家话少，不愿提学校的事，睡眠饮食正常
风险等级：中等（无自伤倾向，但社交退缩持续，需持续关注）
下一步动作：
- 心理老师每周一次辅导（已安排）
- 每周三班主任面谈跟进
- 安排陈xx主动邀请参与课间活动
- 12月初评估是否需升级干预
```

## 示例 2｜阶段摘要

```text
刘xx 在 第11-12周 内，主要关注点为情绪低落与社交退缩。
阶段表现：
- 学习：作业按时但质量下降，课堂参与减少
- 纪律：无违纪，上课走神增多

- 同伴互动：明显减少，回避原有好友
当前判断：中等风险，无自伤倾向，社交退缩持续
后续安排：心理老师每周辅导；班主任每周三面谈；同伴支持（陈xx）；12月初评估
```
