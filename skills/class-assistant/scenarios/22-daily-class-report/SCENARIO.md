     1|# 场景 22｜班级日报
     2|
     3|## 场景目标
     4|把一天内班级出勤、学习、纪律、活动与异常情况整理成一份简洁、可留痕、便于交接的日报。
     5|
     6|## 适用时机
     7|- 需要记录当天班级整体运行情况
     8|- 需要向搭班老师、年级组或自己留档汇总
     9|- 需要把零散事件整理成结构化日报
    10|- 需要为后续跟进保留依据
    11|- 不适合替代正式事故报告或处分材料
    12|
    13|## 输入
    14|- 必填信息：日期、班级、当天重点情况
    15|- 可选信息：出勤、学习、作业、纪律、活动、家校沟通、异常事项
    16|- 缺失时默认：按“基本情况—重点事件—后续跟进”输出
    17|
    18|## 输出
    19|- 默认输出：一版内部班级日报
    20|- 可选输出：精简交接版、简要汇报版、周报素材版
    21|- 输出对象：班主任、搭班老师、内部记录
    22|
    23|## 推荐语气
    24|- 客观
    25|- 简洁
    26|- 条理清楚
    27|- 不情绪化
    28|- 便于追踪
    29|
    30|## 文件说明
    31|- `templates.md`：日报结构模板
    32|- `examples/`：脱敏输入输出样例
    33|- `scripts/`：如后续需要可接入自动汇总脚本
    34|
    35|## 直接给 AI 的说法
    36|- 请把今天班级情况整理成一版内部日报。
    37|- 请根据这些零散记录，按出勤、纪律、学习、跟进事项归类。
    38|- 请生成一版适合和搭班老师交接的班级日报。
    39|
    40|## 注意事项
    41|- 默认用于内部，不直接外发家长群
    42|- 记录以事实为主，不写夸张判断
    43|- 涉及敏感学生情况时，控制披露范围
    44|

## 风格要求
输出风格严格遵循 `skills/VOICE_ANCHOR.md`。禁止使用套话式鼓励、万能结尾、空泛形容词。
