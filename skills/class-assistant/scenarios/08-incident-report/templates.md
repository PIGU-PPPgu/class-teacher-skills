# 模板｜突发事件上报 / 情况说明

## 模板 1｜标准情况说明
**用：** 内部记录、年级组说明

```markdown
## 情况说明

**时间：** [时间]
**地点：** [地点]
**涉及人员：** [涉及人员]

### 事件经过
[客观描述经过，只写事实]

### 现场处理
- [处理措施1]
- [处理措施2]

### 当前状态
[当前状态]

### 后续跟进
- [后续动作1]
- [后续动作2]
```

## 模板 2｜极简留痕
**用：** 先记录，后续补充

```markdown
- 时间：[时间]
- 地点：[地点]
- 事件：[经过简述]
- 已处理：[处理措施]
- 待跟进：[后续事项]
```

## 注意
- 先写经过，再写处理
- 信息未核实标注"据现场了解"或"初步情况"
- 不写情绪评价
