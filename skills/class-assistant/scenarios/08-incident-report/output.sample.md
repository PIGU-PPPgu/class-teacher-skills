# 输出示例｜突发事件上报 / 情况说明

## 示例 1｜标准情况说明

```markdown
## 情况说明

**时间：** 3月12日 14:25
**地点：** 教学楼3楼走廊
**涉及人员：** 张伟（七年级3班）、李强（七年级5班）

### 事件经过
据现场了解，两人因走廊碰撞发生口角，张伟推了李强一下，李强右手肘磕到墙壁。周围同学拉开并通知值周老师。

### 现场处理
- 值周老师将两人带至办公室分开谈话
- 校医检查李强右肘，表皮擦伤，无骨折
- 分别联系双方家长到校

### 当前状态
双方家长已到校沟通，李强伤情无碍。张伟承认推人，已道歉。

### 后续跟进
- 张伟写情况说明，班主任跟进教育
- 本周班会上重申课间纪律
- 持续观察两人关系
```
