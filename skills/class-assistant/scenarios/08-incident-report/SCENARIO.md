     1|# 场景 08｜突发事件上报 / 情况说明
     2|
     3|## 场景目标
     4|帮助老师把突发事件、学生异常情况或处理经过整理成客观、克制、可留档的情况说明，适用于内部上报、后续记录或家校沟通前的底稿准备。
     5|
     6|## 适用时机
     7|- 班级内发生突发小事件需要留痕时
     8|- 需要向年级组 / 学校做简要情况说明时
     9|- 需要先形成处理经过底稿，再决定是否对外沟通时
    10|
    11|不适合：
    12|- 代替正式调查结论
    13|- 未核实清楚就做责任认定
    14|- 对外公开包含敏感隐私的完整细节
    15|
    16|## 输入
    17|### 必填
    18|- 事件时间
    19|- 事件地点
    20|- 事件经过
    21|- 已采取处理措施
    22|
    23|### 可选
    24|- 涉及人员
    25|- 当前状态
    26|- 后续处理建议
    27|- 输出对象（内部记录 / 家长沟通底稿 / 学校上报）
    28|
    29|### 缺失时默认处理
    30|- 未给输出对象：默认内部记录口径
    31|- 未给当前状态：不强行推断
    32|- 未给后续建议：保留待跟进项
    33|
    34|## 输出
    35|默认输出：
    36|- 1 份情况说明 / 事件记录
    37|
    38|可选输出：
    39|- 更正式上报版
    40|- 家长沟通底稿版
    41|- 极简留痕版
    42|
    43|## 推荐语气
    44|- 客观
    45|- 审慎
    46|- 去情绪化
    47|- 留痕导向
    48|
    49|## 文件说明
    50|- `templates.md`：情况说明模板
    51|- `examples/`：脱敏输入输出样例
    52|
    53|## 直接给 AI 的说法
    54|- 帮我整理一份今天这件事的情况说明
    55|- 帮我写成给年级组看的内部上报版
    56|- 帮我先做一个家长沟通底稿
    57|
    58|## 注意事项
    59|- 只写已知事实与处理动作
    60|- 不提前定责
    61|- 不夸大冲突程度
    62|- 涉及未成年人时尽量最小披露
    63|
