# 输出示例｜家长会总结与后续跟进

## 示例 1｜标准总结

```text
【家长会总结】2024-11-22 19:00 七（3）班
会议主题：期中家长会

一、会议概况
到场 45/48 人（3 人请假后补）。会议时长 90 分钟。科任老师语文、数学、英语均到场发言。

二、核心内容
- 期中成绩分析：班级均分年级第3，数学进步最大（+4分）
- 学习习惯要求：每日作业签字、错题本落实、阅读打卡
- 安全与纪律：课间禁止追逐，放学接送准时

三、家长关注点
- 作业量是否过大（5位家长反映）
- 数学尾部学生如何补弱（3位家长提问）
- 英语写作提升方法（2位家长提问）

四、老师提醒
- 作业签字需每日落实，不补签
- 12月进入期末复习，节奏加快
- 关注孩子情绪变化，及时沟通

五、后续安排
- 数学补弱小组下周一启动（每周二、四中午）
- 英语写作专项材料周五发群
- 全体家长一对一沟通计划 12月底前完成

六、需单独跟进事项
- 刘xx家长约周三面谈（情绪问题）
- 王xx家长补开家长会内容
- 张xx家长反映孩子说被孤立，需核实
```
