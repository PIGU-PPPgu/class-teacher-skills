     1|# 场景 04｜成绩分析结论输出
     2|
     3|## 场景目标
     4|把原始成绩、排名、进步退步情况整理成老师能快速阅读的结论稿，便于班级复盘、重点学生识别、家长会准备与后续跟进。
     5|
     6|## 适用时机
     7|- 一次考试后需要快速形成班级分析
     8|- 需要找出进步最大、退步明显、重点关注学生时
     9|- 需要把数据结论转换成文字报告时
    10|
    11|不适合：
    12|- 数据明显缺失或口径不一致但仍强行下结论
    13|- 用公开文本暴露学生隐私
    14|- 用一次成绩给学生贴长期标签
    15|
    16|## 输入
    17|### 必填
    18|- 成绩数据 / 汇总结果
    19|- 分析目标（班级整体 / 重点学生 / 进退步 / 学科对比）
    20|
    21|### 可选
    22|- 班级平均分
    23|- 及格率 / 优秀率
    24|- 上次考试对比数据
    25|- 重点关注名单
    26|- 输出风格（简版 / 标准 / 汇报版）
    27|
    28|### 缺失时默认处理
    29|- 没有对比数据：只做本次横向结论
    30|- 没有统计指标：以已有数据为准，不虚构数字
    31|- 没有风格要求：默认标准结论稿
    32|
    33|## 输出
    34|默认输出：
    35|- 1 份成绩分析结论稿
    36|
    37|可选输出：
    38|- 班级整体总结
    39|- 重点学生名单与建议
    40|- 家长会可用版本
    41|- 年级组汇报版
    42|
    43|## 推荐语气
    44|- 客观
    45|- 聚焦结论
    46|- 少空话
    47|- 可执行
    48|
    49|## 文件说明
    50|- `templates.md`：成绩分析结论模板
    51|- `examples/`：脱敏输入输出样例
    52|
    53|## 直接给 AI 的说法
    54|- 帮我把这次月考成绩整理成班级分析
    55|- 找出这次考试重点关注学生
    56|- 帮我出一个家长会能用的成绩总结
    57|
    58|## 注意事项
    59|- 结论与数据要一致
    60|- 不把偶发成绩波动直接上升为能力定性
    61|- 涉及个人数据时优先脱敏
    62|

## 风格要求
输出风格严格遵循 `skills/VOICE_ANCHOR.md`。禁止使用套话式鼓励、万能结尾、空泛形容词。
