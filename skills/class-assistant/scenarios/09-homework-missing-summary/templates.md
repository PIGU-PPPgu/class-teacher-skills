# 模板｜作业未交 / 迟交汇总

## 模板 1｜群内提醒
**用：** 班级统一催交
**字段：** [作业名称] [截止时间] [未交人数/名单] [补交截止] [提交方式]

```text
各位家长好：
[作业名称] 截止时间为 [截止时间]
未交：[未交人数或名单]
请于 [补交截止] 前通过 [提交方式] 补交
特殊情况请私信说明

班主任
[日期]
```

## 模板 2｜一对一提醒
**用：** 私聊家长催交
**字段：** [学生称呼] [作业名称] [截止时间] [补交截止] [备注]

```text
[家长称呼]好，[学生称呼]的 [作业名称] 截至目前未交。
麻烦关注，于 [补交截止] 前补交。
[备注]
```

## 模板 3｜内部记录
**用：** 留痕、后续跟进
**字段：** [作业名称] [截止时间] [未交名单] [迟交名单] [处理动作] [后续安排]

```text
【作业记录】
作业：[作业名称]
截止：[截止时间]
未交：[未交名单]
迟交：[迟交名单]
已处理：[处理动作]
后续：[后续安排]
```
