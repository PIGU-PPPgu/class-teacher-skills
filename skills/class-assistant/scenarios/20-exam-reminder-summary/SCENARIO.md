     1|# 场景 20｜考前提醒 / 考后总结
     2|
     3|## 场景目标
     4|围绕考试前准备和考试后复盘，快速生成一版清楚、可执行、不过度施压的提醒稿或总结稿。
     5|
     6|## 适用时机
     7|- 单元测试、期中、期末前的准备提醒
     8|- 考后需要对班级整体状态做简要总结
     9|- 需要给家长或学生同步考试相关安排
    10|- 需要把“提醒”与“总结”分开结构化输出
    11|- 不适合替代正式成绩分析报告
    12|
    13|## 输入
    14|- 必填信息：考试类型、时间或阶段、提醒重点 / 总结重点
    15|- 可选信息：班级近期状态、考试要求、常见问题、后续改进方向、发布对象
    16|- 缺失时默认：优先输出通用且明确的提醒，不夸大结果
    17|
    18|## 输出
    19|- 默认输出：一版考前提醒或考后总结
    20|- 可选输出：家长群版、学生班内版、老师内部复盘版
    21|- 输出对象：学生、家长、老师内部
    22|
    23|## 推荐语气
    24|- 清楚
    25|- 稳定
    26|- 鼓励
    27|- 不制造焦虑
    28|
    29|## 文件说明
    30|- `templates.md`：考前提醒与考后总结模板
    31|- `examples/`：脱敏输入输出样例
    32|- `scripts/`：如后续有成绩联动脚本，可放这里
    33|
    34|## 直接给 AI 的说法
    35|- 帮我写一版考前提醒，语气稳一点，不要制造紧张感。
    36|- 根据这次考试情况，生成一版班级层面的简短考后总结。
    37|- 把下面信息分别整理成“考前提醒版”和“考后复盘版”。
    38|
    39|## 注意事项
    40|- 默认先生成草稿，不直接外发
    41|- 不渲染焦虑，不用排名羞辱学生
    42|- 涉及成绩数据时，只写已确认结论，避免误报
    43|

输出风格严格遵循 `skills/VOICE_ANCHOR.md`。禁止使用套话式鼓励、万能结尾、空泛形容词。
