# 模板｜班会提纲

## 模板 1｜常规班会
**用：** 每周班会

```text
班会：[主题]
班级：[班级]
时长：[时长]

一、开场（2分钟）
结合近期情况引出主题：[近期情况]

二、重点（10分钟）
1. [重点1]
2. [重点2]
3. [重点3]

三、互动（5分钟）
- 提问：[问题]
- 自查：[自查任务]

四、收尾（2分钟）
- 重申要求
- 布置落实：[任务]
```

## 模板 2｜专题班会
**用：** 安全、纪律、学习习惯专题

```text
班会：[专题主题]

一、导入
用[案例]说明为什么今天讨论这个。

二、展开
1. 现状是什么
2. 原因在哪
3. 后果是什么

三、讨论
- [问题1]
- [问题2]

四、行动
- [行动1]
- [行动2]
- [行动3]

五、收尾
一句话总结，明确本周落实要求。
```
